# spine-layout-tests

**Live demo:** https://cyberdex.github.io/spine-layout-tests/

A PixiJS + Spine layout test harness. On every push to `main`, GitHub Actions
builds the app and deploys it to GitHub Pages (see
[.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

## Development

```bash
pnpm install
pnpm dev      # local dev server on http://localhost:8080
pnpm build    # production build into dist/
```
